# Новый вариант: простое решение «два прохода»

Самостоятельный комплект простого решения задачи обезличивания CIM-модели. Проверен на настоящей
модели `input.xml` (921 МБ, 741 550 объектов): около 4 минут, `check.py` — «Проблем не найдено».

С чего начать:

* [ПОШАГОВАЯ_ИНСТРУКЦИЯ_КАК_СДЕЛАТЬ.md](ПОШАГОВАЯ_ИНСТРУКЦИЯ_КАК_СДЕЛАТЬ.md) — как **сделать** решение самому,
  шаг за шагом, на учебной мини-модели;
* [ИНСТРУКЦИЯ_НОВИЧКУ.md](ИНСТРУКЦИЯ_НОВИЧКУ.md) — как **пользоваться** готовой программой.

**Все файлы папки есть в формате Word** — в папке `word/`, список в `00_Список_всех_документов.docx`.
Пересоздать их: `python tools/make_word.py`.

```bash
cd "C:\MX\новый вариант"
```
```bash
python anonymize.py C:\Users\Admin\Downloads\input.xml C:\MX\out\input_anon.xml МОЙ_СЕКРЕТ
```
```bash
python check.py C:\Users\Admin\Downloads\input.xml C:\MX\out\input_anon.xml
```

| Файл | Что это |
|---|---|
| `anonymize.py`, `check.py` | программа обезличивания и проверка результата |
| `anonymize_commented.py`, `check_commented.py` | те же программы с комментарием к каждой строке |
| `dict/` | справочники имён и фруктов |
| `tools/` | разведка модели, просмотр словаря, тесты правил, проверка совпадения версий, перевод в Word |
| `practice/` | учебная мини-модель, её «следующая выгрузка» и учебные скрипты шагов 1–9 |
| `ПОШАГОВАЯ_ИНСТРУКЦИЯ_КАК_СДЕЛАТЬ.md` | как сделать решение самому |
| `ИНСТРУКЦИЯ_НОВИЧКУ.md` | как пользоваться готовой программой |
| `word/` | все файлы папки в формате Word (27 документов) |

Отличие от варианта 2 (`C:\MX\v2_two_pass_vault\real_model`): нет хранилища соответствий, поэтому при
обезличивании **обновлённой** модели часть названий меняется. Для разовой передачи модели это не важно.
